# Goldmap — ТЗ для Claude Code

Nov 23, 2026 · @Yurii

## Огляд

Goldmap — мобільний трекер подорожей для iOS і Android: 3D-глобус на чорному фоні, де відвідані країни світяться яскравим золотом, а решта — тьмяним. До кожної країни й точки можна додати фото, нотатки, дати й витрати; окремо — плани майбутніх поїздок. Робоча назва, змінюється.

**Для кого:** для автора і для всіх, хто любить подорожувати; публікація в App Store і Google Play, безкоштовно.

**Принципи, які Claude Code має тримати завжди:**

- **Local-first.** Усі дані й фото зберігаються на телефоні. Жодного власного сервера у версії 1.
- **Офлайн.** Глобус, список країн і всі записи працюють без інтернету. Мережа потрібна лише для детальної карти при наближенні.
- **Без витрат зі зростом аудиторії.** Не підключати сервіси, що беруть гроші за кожного користувача, без окремого рішення.
- **Приватність.** Ніякої аналітики й реклами у версії 1; додаток не збирає даних про користувача.
- **Мова інтерфейсу:** українська й англійська з першого дня (i18n), решта мов — потім.

## Технічний стек

React Native з Expo і TypeScript: один код на обидві платформи, а збірку для iOS робить хмарний EAS, тож Mac не потрібен.

| Частина | Бібліотека | Примітка |
| --- | --- | --- |
| Каркас | Expo (останній SDK), TypeScript strict | Development build, не Expo Go, бо карта має нативний код |
| Навігація | expo-router | Вкладки + модальні екрани |
| Глобус і карта | @rnmapbox/maps, проекція globe | Власний стиль з наших GeoJSON-шарів. Обгорнути в компонент `GlobeView`, щоб можна було замінити на MapLibre |
| База даних | expo-sqlite + Drizzle ORM | Міграції з першого дня |
| Стан | Zustand | Тільки UI-стан; дані — з бази |
| Фото | expo-image-picker, expo-image-manipulator, expo-file-system, expo-image | Стискати до \~2000 px і робити мініатюри |
| Анімації | react-native-reanimated, expo-blur | Затемнення фону й винесення країни |
| Локалізація | i18next + expo-localization | uk, en |
| Бекап | expo-sharing + архів ZIP | Експорт/імпорт усіх даних і фото |
| Збірка і публікація | EAS Build, EAS Submit | Без Mac |

**Карта і гроші.** Mapbox рахує оплату за активних користувачів на місяць понад безкоштовний ліміт. На старті це $0, але перед публікацією перевірити ліміт на mapbox.com/pricing і тримати план Б: MapLibre з безкоштовними тайлами.

**Структура проєкту:**

```
app/            # екрани (expo-router)
  (tabs)/       # Глобус, Країни, Поїздки, Налаштування
  country/[iso].tsx
  trip/[id].tsx
src/
  components/   # GlobeView, CountryCard, StatsCounter, PhotoGrid ...
  db/           # схема Drizzle, міграції, запити
  data/         # countries.json, borders.geojson, cities.json
  theme/        # кольори, шрифти, відступи
  i18n/         # uk.json, en.json
  lib/          # фото, експорт, валюти
CLAUDE.md       # правила проєкту для Claude Code
```

## Дизайн

Темна тема з золотом та єдиним акцентним кольором; всі значення живуть в `src/theme`, жодних кольорів прямо в компонентах.

| Токен | Значення | Де |
| --- | --- | --- |
| `bg` | #000000 | Фон додатку і космос навколо глобуса |
| `surface` | #111111 | Картки, віджети |
| `ocean` | #050505 | Океан на глобусі (ледь світліший за фон) |
| `gold` | #D4AF37 | Відвідані країни, головні кнопки, лічильник |
| `goldDim` | #D4AF37, 18% непрозорості | Невідвідані країни |
| `goldBorder` | #D4AF37, 45% | Контури країн |
| `planned` | #D4AF37 штриховкою або пульсацією | Країни запланованих поїздок |
| `text` | #F5F0E1 | Основний текст |
| `textMuted` | #8A8578 | Другорядний текст |

**Глобус:**

- При відкритті повільно обертається (\~3° за секунду); перший дотик зупиняє обертання.
- Легке золоте світіння атмосфери по краю (Mapbox fog / atmosphere).
- Жести: обертання одним пальцем, наближення щипкою, тап по країні відкриває її картку.
- З далека видно лише контури країн; при наближенні (zoom ≥ 4) з'являються столиці й великі міста точками, при zoom ≥ 6 — точки користувача з мініатюрами фото.
- Після позначки «був тут» країна плавно наливається золотом (\~600 мс) і спрацьовує легка вібрація.

**Шрифти:** заголовки і лічильник — серифний Lora (м'якший за Playfair Display), текст — Inter. Обидва з Google Fonts, підтримують кирилицю.

## Екрани і функції

Чотири вкладки внизу (Глобус, Країни, Поїздки, Налаштування) плюс два детальні екрани: країна і поїздка.

### 1. Головний екран — Глобус

- Глобус на весь екран.
- Зверху лічильник **19 / 193** великим золотим шрифтом, під ним відсоток світу та кількість континентів. Тап — екран статистики (по континентах, по роках).
- Внизу горизонтальна стрічка-віджет **запланованих поїздок**: прапор, країна, «через 12 днів». Тап — глобус повертається до цієї країни.
- Кнопка пошуку країни або міста.
- **Вибір країни (тап):** решта екрану затемнюється і розмивається, а контур країни «виїжджає» на передній план як окрема картка: прапор, назва, столиця, статус і кнопки «Був тут», «Запланувати», «Відкрити».

### 2. Країни

- Перемикач: **Відвідані / Заплановані / Всі**.
- Рядок: прапор, країна, столиця, дати візитів («бер. 2024, серп. 2025»).
- Сортування: за датою, абеткою, континентом. Пошук за назвою.
- У режимі «Всі» — швидка позначка галочкою (зручно, коли новий користувач заповнює свої 20 країн за хвилину).

### 3. Картка країни

- Шапка: контур країни золотом, прапор, столиця, континент, валюта.
- **Візити:** список періодів (з — по), можна додати кілька.
- **Фото:** сітка, додавання з галереї (декілька за раз), перегляд на весь екран.
- **Точки:** міні-карта країни; довге натискання ставить точку з назвою, нотаткою й фото. Якщо у фото є GPS в EXIF — запропонувати поставити точку автоматично.
- **Нотатки:** вільний текст.
- **Витрати:** сума, валюта, категорія (дорога, житло, їжа, розваги, інше), дата, коментар. Підсумок у валюті користувача і діаграма за категоріями.

### 4. Поїздки

- Список поїздок: майбутні зверху, минулі нижче.
- Поїздка = назва, дати, одна або кілька країн, бюджет, список місць «хочу відвідати».
- **Запропоновані місця:** при плануванні показати 5–10 відомих місць країни, які можна додати в план одним тапом. Джерело — див. Відкриті питання.
- Коли дата поїздки минає — запитати «Позначити країни як відвідані?».

### 5. Налаштування

- Мова, основна валюта.
- Список країн для лічильника: **193 країни ООН** або **розширений** (+ Ватикан, Палестина, Тайвань, Косово тощо).
- Експорт і імпорт бекапу, видалення всіх даних.
- Політика конфіденційності, версія додатку, атрибуції карт (© Mapbox, © OpenStreetMap — обов'язково).

## Модель даних

SQLite на телефоні, сім таблиць. Довідник країн у базу не пишеться — він лежить у `src/data/countries.json` і зв'язується за кодом ISO.

| Таблиця | Поля | Примітка |
| --- | --- | --- |
| `visits` | id, country\_iso, start\_date?, end\_date?, created\_at | Кілька записів на країну = кілька поїздок. Країна вважається відвіданою, якщо є хоч один запис |
| `trips` | id, title, start\_date?, end\_date?, budget?, currency?, status (planned / done), notes? | Заплановані й минулі поїздки |
| `trip_countries` | trip\_id, country\_iso | Поїздка може охоплювати кілька країн |
| `places` | id, country\_iso, trip\_id?, title, lat, lng, note?, is\_wishlist, visited\_at? | Точки на карті і місця «хочу відвідати» |
| `photos` | id, country\_iso, place\_id?, file\_uri, thumb\_uri, width, height, taken\_at?, lat?, lng? | Файли лежать у documentDirectory/photos, у базі тільки шляхи |
| `notes` | id, country\_iso, trip\_id?, text, created\_at, updated\_at | Нотатки до країни чи поїздки |
| `expenses` | id, country\_iso, trip\_id?, amount, currency, category, date, comment? | Суми зберігати в мінімальних одиницях (копійки, центи) цілими числами |
| `settings` | key, value | Мова, основна валюта, режим списку країн |

Правила:

- Усі id — UUID, дати — ISO-рядки `YYYY-MM-DD`. Це спрощує майбутню синхронізацію.
- Кожна таблиця має `updated_at` і `deleted_at` (м'яке видалення) — теж під синхронізацію у версії 2.
- Курси валют для підсумку: у версії 1 користувач рахує в одній основній валюті або вводить курс вручну; автоматичні курси — пізніше.

## Дані країн і кордони

Усі довідкові дані вшиваються в додаток файлами, тому глобус і список працюють офлайн.

| Файл | Джерело | Що зробити |
| --- | --- | --- |
| `borders.geojson` | Natural Earth, Admin 0 Countries, версія «точка зору України» (файли з суфіксом `_ukr`) | Спростити через mapshaper до 1–3 МБ; використовувати масштаб 1:50m |
| `countries.json` | Датасет mledoze/countries або аналог | Лишити: iso2, iso3, назви uk/en, столиця, континент, валюта, прапор-емодзі, прапорець `un_member`, центр (lat/lng) |
| `cities.json` | Natural Earth Populated Places або GeoNames (міста понад 100 тис.) | Назва, країна, lat/lng, столиця так/ні |

**Кордони — непереговорна вимога:** Крим і всі тимчасово окуповані території відображаються як Україна. Після підготовки файлу Claude Code має запустити перевірку: точка Сімферополя (44.95, 34.10) належить полігону UA. Те саме для міст у `cities.json`.

**Лічильник.** Знаменник за замовчуванням — 193 (члени ООН). У розширеному режимі — усі території з файлу. Території не з списку ООН (Гренландія, Пуерто-Ріко тощо) можна позначати завжди, але в базовий лічильник вони не йдуть.

**Ліцензії.** Natural Earth — суспільне надбання. Для countries.json і GeoNames перевірити ліцензію (ODbL / CC BY) і додати атрибуцію в налаштування.

## Етапи розробки

Дев'ять етапів; після кожного додаток запускається на телефоні й перевіряється руками, а зміни зберігаються комітом у git. Один етап = одна сесія Claude Code.

**Як працювати:** поклади цей документ у папку проєкту як `docs/SPEC.md` (експорт у Markdown), а перед кожним етапом кажи Claude Code: «Прочитай docs/SPEC.md і зроби етап N». Використовуй режим планування (Shift+Tab), щоб спершу побачити план.

1. **Каркас.** Створити Expo-проєкт з TypeScript і expo-router, 4 порожні вкладки, тему з розділу «Дизайн», шрифти, i18n (uk/en), ESLint + Prettier. Створити `CLAUDE.md` з принципами з «Огляду». Готово, коли: додаток відкривається на телефоні, вкладки перемикаються.
2. **Дані країн.** Скрипт `scripts/build-data`, який готує `borders.geojson`, `countries.json`, `cities.json` за розділом «Дані країн», і тест на кордони України. Готово, коли: тест зелений, файл кордонів ≤ 3 МБ.
3. **База даних.** Схема Drizzle з розділу «Модель даних», міграції, функції-запити (додати візит, список відвіданих, лічильник) і unit-тести до них.
4. **Глобус.** Mapbox у development build, `GlobeView` з чорним фоном, золотими відвіданими й тьмяними іншими країнами, автообертанням, столицями при наближенні, лічильником `N / 193`. Готово, коли: глобус крутиться плавно (60 кадрів/с) на твоєму телефоні.
5. **Вибір країни і «Був тут».** Тап по країні → затемнення фону і винесена картка; позначка з анімацією золота й вібрацією; вкладка «Країни» зі списком, прапорами, столицями й датами.
6. **Картка країни.** Візити, фото (стиснення + мініатюри), нотатки, витрати з категоріями і підсумком.
7. **Точки на карті.** Довге натискання ставить точку; фото і нотатка до точки; пропозиція точки з GPS у фото; точки з мініатюрами на глобусі.
8. **Поїздки.** Створення поїздки, віджет на головній, список «хочу відвідати», запит «позначити відвіданими?» після дати. Запропоновані місця — після рішення щодо джерела.
9. **Фініш.** Експорт/імпорт ZIP, налаштування, екран першого запуску («Познач країни, де ти вже був»), іконка й splash-екран, перевірка продуктивності на слабкому Android.

**Промпт для старту (етап 1):**

```
Прочитай docs/SPEC.md повністю. Зроби етап 1 «Каркас».
Спочатку покажи план і список залежностей, дочекайся мого «ок».
Створи CLAUDE.md з принципами проєкту (local-first, офлайн,
кольори тільки з src/theme, тексти тілько через i18n).
В кінці напиши, як запустити додаток на моєму телефоні.
```

Вихід в обидва магазини коштує $124 у перший рік і $99 щороку далі; Google треба починати раніше через 14-денне тестування.

| Магазин | Вартість | Особливості |
| --- | --- | --- |
| Google Play | $25 одноразово | Для нових особистих акаунтів — закритий тест: ≥ 12 тестувальників упродовж 14 днів поспіль; верифікація особи |
| App Store | $99 на рік | Суворіша перевірка, зазвичай 1–3 дні; тест через TestFlight |

**Чекліст:**

- [ ] Зареєструвати Google Play Console і зібрати 12+ тестувальників (друзі з Android)
- [ ] Зареєструватися в Apple Developer Program
- [ ] Акаунт Expo і налаштований `eas.json` (development, preview, production)
- [ ] Політика конфіденційності на GitHub Pages: дані зберігаються лише на пристрої, доступ до фото тільки за вибором користувача, карти Mapbox
- [ ] Тексти дозволів iOS (фототека, локація з фото) українською й англійською
- [ ] Privacy labels (App Store) і Data safety (Google Play): «дані не збираються»
- [ ] Іконка 1024×1024, скріншоти для телефонів, опис uk/en, ключові слова
- [ ] Перевірити, що назва вільна в обох магазинах
- [ ] Атрибуції Mapbox / OpenStreetMap видно на карті
- [ ] Якщо пізніше з'являться акаунти: Sign in with Apple і видалення акаунта в додатку
