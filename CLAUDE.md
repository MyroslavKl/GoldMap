# Goldmap — правила проєкту

Мобільний трекер подорожей (iOS + Android): 3D-глобус, відвідані країни світяться золотом.
Повне ТЗ — `docs/SPEC.md`. Перед кожним етапом прочитай його; один етап = одна сесія = один коміт.

## Принципи (тримати завжди)

1. **Local-first.** Усі дані й фото — лише на телефоні (SQLite + `documentDirectory`).
   Жодного власного сервера у версії 1.
2. **Офлайн.** Глобус, список країн і всі записи працюють без інтернету. Довідкові дані
   (країни, кордони, міста), шрифти й іконки вшиті в додаток. Мережа — лише для детальних
   тайлів карти при наближенні.
3. **Без витрат зі зростом аудиторії.** Не підключати сервіси з оплатою за користувача
   (MAU, запити, місця) без окремого рішення автора. Сумніваєшся — спитай.
4. **Приватність.** Ніякої аналітики, реклами, трекінгу, crash-репортерів з передачею даних.
   Додаток не збирає даних про користувача.
5. **Кольори — тільки з `src/theme`.** У компонентах жодних `#hex`, `rgb()`, `'white'`:
   лише `colors.*` (і `goldAlpha()` для прозорості). Потрібен новий колір — додай токен у
   `src/theme/colors.ts`. Перевіряє ESLint (`no-restricted-syntax`).
6. **Тексти — тільки через i18n.** Увесь видимий текст — `t('key')`, ключі в `src/i18n/uk.json` і
   `src/i18n/en.json` (обидві мови одночасно, ключі типізовані за `en.json`). Літерали в JSX
   заборонені (`react/jsx-no-literals`). Те саме для accessibility-підписів і заголовків екранів.
7. **Кордони.** Крим і всі тимчасово окуповані території — це Україна (Natural Earth `_ukr`).
   Не змінювати без перевірки Сімферополя (44.95, 34.10) ∈ UA.

## Стек

Expo SDK 58 (React Native, TypeScript strict), expo-router, expo-sqlite + Drizzle, i18next +
expo-localization. Далі за етапами: Zustand лише для UI-стану.

**Глобус: зараз WebView, перед публікацією — нативний Mapbox.** У автора iPhone без Apple
Developer акаунта, тож development build на iOS неможливий, а додаток має працювати в **Expo Go**.
Тому `GlobeView` зараз — MapLibre GL JS (globe) у react-native-webview; перед публікацією його
замінить @rnmapbox/maps (див. `docs/SPEC.md` → «Технічний стек», «Публікація»). Правила:

- Глобус — тільки через `@/components/globe` (`GlobeView`, `GlobeViewProps`, `GlobeViewHandle`).
  `react-native-webview`, `maplibre-gl` і `web/*` поза `src/components/globe` не імпортувати.
- Контракт у `types.ts` не залежить від реалізації: жодних WebView/MapLibre-типів у пропсах.
  Нова можливість глобуса = пропс/команда в `types.ts` + реалізація, яку потім повторить Mapbox.
- Не додавати нативних модулів, яких немає в Expo Go, без рішення автора.
- Код у WebView — `src/components/globe/web/main.ts`; кольори імпортує з `src/theme/colors.ts`.
  RN ⇄ WebView — лише типізовані повідомлення з `protocol.ts`.
- `web/globe-html.generated.ts` генерується (`npm run build:globe`, автоматично після
  `npm install`), у git не потрапляє, руками не редагувати. Після змін у `web/main.ts`, темі чи
  `src/data` — перезібрати.
- Офлайн: MapLibre, його воркер (Blob URL), кордони, міста, точки підписів і шрифт Inter (style
  `font-faces`, data: URL — текст малюється локально) вшиті в HTML. Сервера гліфів, спрайтів чи
  шрифтів з мережі немає; це перевіряє `npm run test:globe`.
- **Єдиний виняток — детальна карта** (`web/detail-layers.ts`): векторні тайли OpenFreeMap
  (TileJSON `tiles.openfreemap.org/planet`, без ключа) з zoom ≥ 6 і лише коли є інтернет
  (`detailMap` ← `useDetailMapAllowed()`, expo-network). З тайлів — тільки вода, річки, дороги,
  забудова й назви населених пунктів. Шар `boundary` і підписи країн/регіонів **не підключати
  ніколи**: кордони лише наші (Крим — Україна); є тест. Атрибуція «© OpenFreeMap © OpenMapTiles
  © OpenStreetMap» — на карті, поки видно тайли.
- Мініатюри точок: WebView не має доступу до файлів додатку, тож RN читає `…_t.jpg` і передає
  data: URL на запит (`needThumb` → `pointThumb`), лише для точок у кадрі при zoom ≥ 6.
- **Одна WebView-карта за раз.** Екран з мінікартою викликає `useHoldsMap()`
  (`src/lib/map-presence.ts`) — вкладка «Глобус» вивантажує свою WebView і потім відновлює камеру
  (`initialCamera`). Мінікарта створюється після анімації переходу.
- Мінікарта (`focus`) — лише своя країна: наближення й рух є, але після жесту камера плавно
  повертається в межі країни і не віддаляється далі за всю країну (у проєкції globe MapLibre не
  застосовує `maxBounds`/`minZoom` — обмежуємо самі, на `moveend`). Сусідні країни приглушені;
  тап і довге натискання поза країною ігноруються.
- Автообертання (~3°/с) зупиняється від дотику й відновлюється через 5 с без дій, лише якщо
  глобус віддалений (zoom ≤ 2) — наближений до країни глобус стоїть (`web/main.ts`).
- Сонячна система при віддаленні (`web/solar.ts` — геометрія, чиста й тестована; малювання —
  полотно `#space` під `#world` у `web/main.ts`). Глобус = Земля: увесь `#world` зсувається й
  зменшується CSS-трансформом. Назви — пропс `spaceLabels` з i18n (`space.*`), кольори —
  `colors.space.*`. Малюється лише коли видно (progress > 0), у мінікарті вимкнено. Поки видно
  систему, `#map` не ловить дотиків (CSS-масштаб зменшив би й зону дотику до крихітної Землі) —
  щипок, крутіння й подвійний тап по всьому екрану обробляє `main.ts` сам.
- Жести: щипок двома пальцями — завжди власний обробник у `main.ts` у координатах екрана
  (`touchZoomRotate` MapLibre вимкнено: під CSS-масштабом Сонячної системи він «боровся» сам із
  собою); наближення відносно центру, без повороту карти, один жест проходить межу космосу. Подвійний тап —
  наближення на крок. Через це одиночний тап по країні спрацьовує із затримкою ~0,3 с.
- Кордони поверх золота (між відвіданими сусідами) — темний пунктир `borderOnGold`, інакше
  межа зливається із заливкою.
- Ліцензія MapLibre GL JS — BSD-3-Clause: текст має бути в «Атрибуціях» (етап 9).

- Пакети ставити **тільки** `npx expo install <pkg>` (сумісні з SDK версії).
- Expo змінюється з кожним SDK — не покладайся на пам'ять, звіряйся з
  `https://docs.expo.dev/versions/v58.0.0/`.
- `ios/` і `android/` генеруються (CNG) і в git не потрапляють. Нативні налаштування — через
  `app.json` і config-плагіни.
- Нативні модулі поза Expo Go (Mapbox тощо) потребують development build (EAS) — до публікації
  їх не додаємо (див. вище).

## Структура

```
app/                  # маршрути expo-router (лише екрани й _layout)
  (tabs)/             # Глобус (index), Країни, Поїздки, Налаштування
  country/[iso].tsx   # екран країни (звичайний перехід, не модальний — поверх видно «Скасувати»)
  trip/[id].tsx       # екран поїздки (звичайний перехід)
  inbox.tsx           # «Скринька»: питання після поїздок
src/
  components/         # AppText, Screen, Button, Sheet, DateField, UndoToast, CountryCard ...
    country/          # секції екрана країни: візити, фото, нотатки, витрати
  db/                 # схема Drizzle, міграції, запити
  data/               # countries.json, borders.geojson, cities.json
  theme/              # colors, fonts, spacing, navigationTheme
  i18n/               # uk.json, en.json, ініціалізація
  lib/                # фото, експорт, валюти
docs/SPEC.md          # ТЗ
```

Імпорти з `src` — через аліас `@/…` (`@/theme`, `@/components/AppText`).

## Дані

- id — UUID; дати — рядки `YYYY-MM-DD`; у кожній таблиці `updated_at` і `deleted_at`
  (м'яке видалення).
- Гроші — цілі числа в мінімальних одиницях (копійки, центи).
- Фото — файли в `documentDirectory/photos`, у базі тільки шляхи.
- Довідник країн у базу не пишеться: `src/data/countries.json`, зв'язок за ISO-кодом.
- `src/data/*.json|geojson` — згенеровані (`npm run build:data`), руками не редагувати.
  Джерела закріплені за комітом і SHA-256 у `scripts/data-sources.ts`, ручні правки —
  у `scripts/overrides.ts` (кожна з причиною). Типи — `src/data/types.ts`.
- Кордони — Natural Earth `_ukr` (1:10m, спрощено до ~1 МБ). Країну міста визначає полігон,
  а не поле джерела. Після будь-якої зміни даних — `npm run test:data` (Сімферополь ∈ UA).
- `countries.json` — похідна від mledoze/countries під **ODbL**: атрибуція обов'язкова
  (див. `src/data/LICENSE-DATA.md`).
- Лічильник: 193 члени ООН (Ватикан і Палестина — спостерігачі, не входять). Косово в
  кордонах з точкою зору України — частина Сербії; Мартиніка, Гваделупа, Реюньйон — Франції.

## База даних (`src/db`)

- Схема — `src/db/schema.ts`. Змінив схему → `npm run db:generate` → нова міграція в
  `src/db/migrations` (комітити разом). Старі міграції не редагувати.
- Міграції застосовує `DatabaseGate` при старті додатку (`useMigrations`).
- Функції-запити — `src/db/queries/*`, приймають `DbContext` (`db`, `newId`, `now`) і пишуться
  через `await`: у додатку працюють з expo-sqlite (`dbContext` з `@/db/client`), у тестах — з
  `node:sqlite` (`tests/helpers/test-db.ts`). Компоненти не пишуть SQL напряму.
- Читання завжди фільтрує `deleted_at IS NULL`; видалення — лише м'яке (`deleted_at`, `updated_at`).
- Нова функція-запит = unit-тест у `tests/db.test.ts`.
- Відносні імпорти всередині `src/db` — з розширенням `.ts` (потрібно для Node-тестів;
  Metro їх розуміє). `src/db` не імпортує нічого з `@/…` і з Expo, крім `client.ts`.
- Живі дані в компонентах — `useLiveQuery` з `drizzle-orm/expo-sqlite` (напр. `visitedIsosQuery`).

## Позначка «був тут»

- Позначати / знімати — лише через `useToggleVisited()` (`src/lib/use-toggle-visited.ts`): одна
  логіка для картки на глобусі й галочки у списку (вібрація, підтвердження).
- Перед зняттям позначки, якщо в країни є дати візитів, фото, нотатки чи витрати —
  підтвердження (`needsUnmarkConfirmation`). Зняття видаляє **лише візити**; фото, нотатки й
  витрати не чіпати ніколи (є тест).
- Картка країни на глобусі — оверлей (`CountryCard`) поверх глобуса, не окремий екран.
- Заливка золотом ~600 мс: на глобусі — `web/fill-animator.ts`, у картці — `CountryOutline`.
- Силуети — `src/data/outlines.json` (генерує `build:data`); тест перевіряє, що Сімферополь
  усередині силуету UA.

## Екран країни (етап 6)

- **Візит без дат** (з «Був тут» / галочки) заповнюється першим візитом з датами — `addVisit`
  не створює другого запису (є тест). Наступні візити з датами — окремі записи.
- **Візит — лише минуле:** дати після сьогодні не можна ні в календарі (`maximumDate`), ні в
  базі (`assertNotFuture`, запас +1 день на часовий пояс). Плани — це поїздки (етап 8).
- **Фото** — `src/lib/photos.ts`: копія в `documentDirectory/photos/<id>.jpg` (довша сторона
  ≤ 2000 px, JPEG 0.85) + мініатюра `<id>_t.jpg` (400 px). Не посилання на галерею: фото
  лишається, навіть якщо його видалили з галереї. Дата зйомки й GPS — з EXIF
  (`src/lib/exif.ts`, iOS `{GPS}` і Android-раціонали) у `photos.taken_at/lat/lng`.
  Відображення — лише через `photoUri(relativePath)`.
- **Видалення з «Скасувати».** Фото, нотатка, витрата, візит: м'яке видалення →
  `showUndo({ message, undo, commit })` (`src/lib/undo.ts`, 5 с). Файли фото стираються в
  `commit` після вікна «Скасувати»; при старті — `cleanupDeletedPhotoFiles()` (видалені > 5 хв).
- **Гроші** — `src/lib/money.ts` (чистий, без Intl): мінімальні одиниці за ISO 4217 (JPY — 0,
  KWD — 3 знаки), кожна витрата у своїй валюті. Підсумок — в основній валюті (`settings.currency`,
  за замовчуванням UAH для регіону UA, інакше USD) за ручними курсами
  `settings.exchangeRates` (`'EUR>UAH': 45`). Витрати без курсу в підсумок не йдуть —
  показуються окремо з кнопкою «Вказати курс».
- Діаграма витрат — упорядковані горизонтальні смуги одним кольором (золото), з назвою, сумою
  й часткою в кожному рядку.
- Тексти дозволів (фото) — `locales/uk.json`, `locales/en.json` + плагін expo-image-picker в
  `app.json` (камера й мікрофон вимкнені). В Expo Go не видно — лише в збірці.

## Точки на карті (етап 7)

- Точка = `places` (`is_wishlist = false`, з координатами); фото прив'язуються через
  `photos.place_id` (`setPlacePhotos`). Видалення точки — з «Скасувати»; фото лишаються в країні.
- Довге натискання (~0,5 с) на глобусі чи мінікарті → `PlaceSheet`. На океані — нічого: точка
  завжди належить країні (`iso2` визначає WebView за нашими кордонами).
- Фото з GPS → `src/lib/photo-clusters.ts`: один день + ланцюжок ≤ 1 км = одна точка, назва —
  найближче місто з `cities.json` (офлайн). Країна групи — `locateCountry()` за
  `borders.geojson` (вшитий рядком через inline-import). Інша країна → пропонуємо додати туди
  (країна позначається відвіданою, фото переїжджають) або пропустити (`skippedGpsPhotos`).

## Поїздки (етап 8)

- Поїздка = `trips` + `trip_countries` (м'яке видалення; повернена країна відновлюється —
  `setTripCountries`). Дати поїздки можуть бути в майбутньому (на відміну від візитів).
- «Хочу відвідати» = `places` з `trip_id`, `is_wishlist = true`; з пропозицій — з
  `wikidata_id` (без дублікатів). Після початку поїздки місце позначається відвіданим
  (`markWishlistVisited`) і, якщо має координати, стає точкою на карті.
- Пропозиції — `src/data/landmarks.json` (`npm run build:landmarks`, Wikidata CC0): до 15 на
  країну за кількістю мовних версій статей. Країна — **за нашими кордонами** (тест: Крим — UA);
  мікродержави (Ватикан) — із запасом ~300 м навколо крихітного полігона.
- Витрати прив'язуються до поїздки (`expenses.trip_id`); бюджет проти витрат —
  `budgetProgress` (`src/lib/money.ts`), у валюті бюджету за ручними курсами.
- Після кінця поїздки — попап `TripQuestionCard` при відкритті додатку (`TripsHost` у корені),
  без push. Галочка біля кожної країни: візит з датами поїздки отримують лише вибрані.
  «Пізніше» — `snoozeTripQuestion`: попап для цієї поїздки знову з наступного дня
  (`settings.tripQuestionSnooze`), до того питання лише в «Скриньці» (`app/inbox.tsx`).
- Нагадування перед поїздкою — локальні сповіщення (expo-notifications, у Expo Go працюють):
  за 30/7/3/1 день о 9:00, id `trip-<id>-<днів>` — `syncTripReminders` переплановує все при
  зміні поїздок, мови чи перемикача `settings.tripReminders`. Дозвіл — при першій майбутній
  поїздці. Push із сервера не використовуємо.

## Чисті модулі й тести

- Логіка без React/Expo — у `src/lib/*.ts` (`country-list.ts`, `dates.ts`, `money.ts`,
  `exif.ts`, `geo.ts`, `photo-clusters.ts`, `places.ts`, `trips.ts`) з відносними імпортами `.ts`;
  тести —
  `tests/lib.test.ts` (і додати файл у `tests/tsconfig.json`). Хуки й код з Expo — окремими файлами.
- Назви місяців — з i18n (`months.short`), не з `Intl`: однаково на iOS і Android.

## Команди

```bash
npx expo start         # dev-сервер (Expo Go)
npm run typecheck      # tsc: додаток, scripts, tests
npm run lint           # ESLint (expo + prettier + правила проєкту)
npm run format         # Prettier
npm run build:data     # перезібрати src/data з джерел (потрібен інтернет)
npm run build:landmarks # «варто побачити» з Wikidata → src/data/landmarks.json (інтернет)
npm run test:data      # тести даних (кордони України, 193, назви)
npm run test:db        # unit-тести бази (node:sqlite у пам'яті)
npm run test:lib       # чисті модулі src/lib (список країн, дати, гроші, EXIF) + паритет uk/en
npm test               # усі тести
npm run db:generate    # нова міграція після зміни схеми
npm run build:globe    # перезібрати офлайн-HTML глобуса
npm run test:globe     # тести глобуса (офлайн-HTML, протокол)
npm run check          # typecheck + lint + format:check + усі тести — перед комітом
npx expo-doctor        # перевірка залежностей і конфігу
```

## Як працювати
