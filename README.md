# Goldmap

Мобільний трекер подорожей: 3D-глобус, відвідані країни світяться золотом. Працює офлайн,
усі дані лишаються на телефоні.

- ТЗ: [docs/SPEC.md](docs/SPEC.md)
- Правила для розробки: [CLAUDE.md](CLAUDE.md)

## Запуск

```bash
npm install
npx expo start
```

Відскануй QR-код застосунком **Expo Go** (Android) або камерою (iPhone).
З етапу 4 (Mapbox) потрібна development build через EAS.
